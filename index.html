Open Medication Catalog

A multi-national medication catalog based on open data sources, with stable and reproducible FHIR R4, FHIR R5 (IDMP) and SQLite releases.

Download artifacts Source on GitHub

The generator is Apache-2.0. Each dataset keeps its upstream licence and attribution. Attributions are recorded in the release.

Contents

Release contents

We convert the country-specific formats to standardized formats and offer them for download as-is.

SQLite

Packages, medicinal products, and declarations, with full-text search.

FHIR R4 and R5

R4 Medication per package. R5 MedicinalProductDefinition, PackagedProductDefinition, Ingredient, and RegulatedAuthorization. R5 follows IDMP. It is not ISO IDMP certified.

Source files

Source snapshots, checksums, and licence files. Official zips are binary-reproducible.

Limits

  • No prescribing, interactions, dosing, substitution, or cross-country equivalence.
  • R5 follows IDMP. It is not ISO IDMP certified. Swissmedic routes stay Swissmedic codes until EDQM is verified.
  • A later global catalog is the union of national catalogs.
  • Build attestations are not included yet. Unsigned zips are not for unattended hospital use.

Generator

Build from source

Official builds use recipes in artifacts.yaml. Implementation Guides will be published at fhir.openmedicationcatalog.org in the future. 

pnpm install
pnpm omc build ch-base --month 2026.09
pnpm omc search output/ch-base/release/database/medication.sqlite Metformin

Node.js 22+, pnpm 10. See the repository README.

Licence

Generator and dataset licences

Generator: Apache-2.0

The CLI, adapters, schemas, and Implementation Guide sources are Apache-2.0.

Note that we strictly separate the code from the actual medication catalog data. We don't relicense medication catalog; those come with their respective providers' open licence terms.

Datasets: upstream terms

All catalog data is licensed according to the respective providers' licensing terms. We aim to include only data that carries a licence permissive enough for commercial and non-commercial use. Some licences may require attribution.

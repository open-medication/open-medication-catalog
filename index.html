A multi-national medication catalog based on open data sources, with stable and reproducible FHIR R4, FHIR R5 (IDMP) and SQLite releases.

Contents

Release contents

We convert the country-specific formats to standardized formats and offer them for download as-is.

SQLite

Packages, medicinal products, and declarations, with full-text search.

FHIR R4 and R5

R4 Medication per package. R5 MedicinalProductDefinition, PackagedProductDefinition, Ingredient, and RegulatedAuthorization. R5 follows IDMP. It is not ISO IDMP certified.

Source files

Source snapshots, checksums, and licence files. Official zips are binary-reproducible.

Limits

  • No prescribing, interactions, dosing, substitution, or cross-country equivalence.
  • R5 follows IDMP. It is not ISO IDMP certified. Swissmedic routes stay Swissmedic codes until EDQM is verified.
  • A later global catalog is the union of national catalogs.
  • Build attestations are not included yet. Unsigned zips are not for unattended hospital use.

Generator

Build from source

Official builds use recipes in artifacts.yaml. Implementation Guides will be published at fhir.openmedicationcatalog.org in the future. 

pnpm install
pnpm omc next-month ch-base
pnpm omc build ch-base --month 2026.08
pnpm omc search output/ch-base/release/database/medication.sqlite Metformin

Node.js 22+, pnpm 10. See the repository README.

Licence

Generator and dataset licences

Generator: Apache-2.0

The CLI, adapters, schemas, and Implementation Guide sources are Apache-2.0. We strictly separate that code from the medication catalog data and do not relicense the catalog.

Datasets: upstream terms

Catalog data keeps each provider’s own terms. Download cards show the flags below and a Terms link to the upstream page. Official builds checksum that page and halt redistribution if it no longer matches the reviewed snapshot.

What the flags mean

commercialUse, redistribution, and attributionRequired on each artifact are indicators of our interpretation of the linked upstream terms at the dated review. They are not a licence grant and not legal advice.

Value Meaning
allowed We found an explicit grant for that activity in the linked terms.
disallowed We found an explicit prohibition. The source is not in a public recipe.
review-required Terms are missing, gated, or ambiguous. Not in a public recipe until resolved.

attributionRequired is true or false according to whether those terms ask for attribution.

We are not liable for misinterpreting upstream licences. We are not liable for fitness for a specific purpose, or for legal compatibility or suitability for integration into any downstream product. Every customer bears the responsibility of cross-checking the linked upstream terms before use. We are not in control of how those terms are worded or when they change. The checksum in a release is a snapshot, not a guarantee the live page stays still.
